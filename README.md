# ADR

* Sigle: **FL, AT, EXII, EXIII, MEMU**
* Trasporto: **Colli, Alla RInfusa, In cisterne, In container** *(Tutti)*
* Esplosivi Classe 1: EXII EXIII
* Radiottivi Classe 7: Trasposto solo in colli
* Gas Classe 2
### Identificazione cisterne
* Marchio e numero di fabbrica
* Targhetta metallica (**no adesiva**)
* Punzonatura passo d'uomo

### Documento *Barrato Rosa*
* **Nuove immatricolazioni**
DDT306/M DDT307
* **Vecchie immatricolazioni**
MC813 (MC452 normativa T-PED Classe 2)

### Rinnovo Attestato

* **Rinnovo**: vale **1** anno
* **Attestato**: Rilasciato da **UMC** dopo visita e prova

# Trasporto Specifico/Speciale
> specifico = adatto a una particolare merce **ATP**
> speciale = destinato a un servizio o a un uso particolare

| Tipo | Differenza | Esempi |
|---|---|---|
| **Trasporto specifico** | Veicolo costruito o attrezzato per trasportare una determinata categoria di merci. | Autocisterna per carburanti, camion frigorifero, carro attrezzi, veicolo per animali vivi. **ATP** |
| **Trasporto speciale** | Veicolo destinato a trasportare persone o cose con caratteristiche particolari, per esigenze specifiche. | Autoambulanza, veicolo per trasporto detenuti, veicolo per disabili, veicolo antincendio, autocarro per trasporti eccezionali. |
